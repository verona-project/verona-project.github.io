A small systems language

Native code, clear data, deliberate boundaries.

Verona is a statically typed language with an S-expression syntax. It compiles to native artifacts and makes C interoperability an explicit part of the language model.

Current release: 0.1.0.

Typed native code

Useful base library

Protocols provide numeric operations, equality, ordering, and explicit result-directed conversion.

Native boundary

Import C symbols, publish compatible APIs, and call typed function pointers.
