A small systems language

Native code, clear data, deliberate boundaries.

Verona is a statically typed language with an S-expression syntax. It compiles through LLVM and makes C interoperability an explicit part of the language model.

Current release: 0.1.0.

Typed native code

Verona resolves and validates types before emitting LLVM IR and native artifacts.

Data-oriented syntax

Nominal products and sums make the shape of a program’s data explicit.

A C ABI boundary

Import C symbols and publish supported APIs with generated C headers.
